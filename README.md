# 🚀 Luminous Tech — Facebook Reels Automation & Growth Suite

> Built by **[Faiyaz](https://github.com/faiyazsumon786)**

A professional all-in-one desktop automation platform for Facebook Reels creators, page managers, and digital marketers. Built on Electron and Chrome DevTools Protocol (CDP), **Luminous Tech** combines multi-profile antidetect browser management, automated Reels uploading, anti-copyright protection, AI voice generation, video slicing, and social growth boosting.

---

## ✨ Key Features

### 🛡️ 1. Anti-Copyright Engine (Auto-Uniquifier)
- Automatically micro-crops frames, adjusts subtle audio pitch frequencies, and strips metadata using `ffmpeg-static`.
- Resets video MD5 and SHA hashes for every single profile/page upload, protecting your accounts from duplicate content shadowbans.

### 🎭 2. Auto-Humanizer & Account Warm-up
- Simulates realistic human behavior (feed scrolling, reading pauses, video previewing) before publishing or on-demand.
- Warms up new profiles to build Facebook trust score and bypass automated bot detection.

### ⚡ 3. Hybrid Growth Booster
- **Internal Farm Booster (100% Free):** Uses your own connected profiles to automatically visit and follow/like target Facebook pages, profiles, or react to Reels with randomized human delay.
- **SMM Reseller API Panel:** Connects any standard SMM provider (v2 API format) to check live wallet balances, browse services, calculate estimated costs, and place mass follower/view orders directly from the app.

### 🚀 4. Auto-Pilot (Scheduled Campaigns)
- Set up automated campaigns watching specific video folders.
- Automatically publishes fresh videos to assigned Facebook profiles or pages on a regular interval (e.g. every 2 hours, 6 hours, or daily).

### ✂️ 5. Video Slicer (Long-to-Shorts)
- Chops long podcasts, movie clips, and gaming streams into viral 30s, 60s, or 90s vertical Reels.
- 1-click **"Send All to Reels Upload"** to publish chopped clips instantly.

### 🎙️ 6. AI Voiceover Generator & Merger
- Free high-quality text-to-speech engine supporting Bengali, English, Hindi, Arabic, Spanish, and more.
- Built-in video & audio merger with original audio ducking (mixing background audio with voiceover).

### 💬 7. Auto-Reply to Comments (Engagement Booster)
- Scans viewer comments on your Reels or Page feeds, likes them, and posts natural spintax replies (`{Thanks!|Glad you enjoyed it!}`) to trigger algorithmic virality.

### 📦 8. One-Click Backup & Restore
- Full export of all profiles, cookies, proxies, and Auto-Pilot campaigns to a portable JSON backup file.
- Restore your entire workspace on any PC with a single click.

## 🛠️ Installation & Setup

### Prerequisites
- [Node.js](https://nodejs.org/) v20+ or v22+
- Windows 10/11 (64-bit)

### Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/faiyazsumon786/luminous-tech.git
   cd luminous-tech
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch the application:**
   ```bash
   npm run gui
   ```
   *Or double-click `launch.bat` in the project root folder.*

## 🔒 Privacy & Security

All browser profiles, cookies, and local database files are saved locally on your computer in your private storage directory. **None** of your Facebook accounts, cookies, or credentials are sent to any external server.
